The numbers are always computed by BizPulse itself. When you add a key, each agent's written commentary is generated live by an LLM instead of the built-in writer. Your key is stored only in this browser and is sent directly to the provider you choose.

How it works

The metrics engine. Every figure — profit rate, margins, burn rate, runway, cash flow, break-even — is computed from your data with standard formulas. Each metric shows its formula, so you can check the maths.

The agents. Seven specialists each read the same engine output but focus on one area. They flag what is good, what to watch and what is critical, then give concrete recommendations.

The orchestrator. The lead CFO agent reads every specialist's findings, resolves conflicts and produces one prioritised action list plus an overall health score.

Hybrid AI. Logic computes the numbers; the LLM (when enabled) writes the narrative. With no key, a built-in writer composes the commentary from the same numbers — so nothing ever breaks.
